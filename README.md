# Инструкция по установке и настройке UTM Link Builder

Этот сервис предназначен для генерации маркетинговых ссылок. Данное руководство описывает требования к серверу, процесс установки и безопасности.

## 1. Требования к VPS
Для работы сервиса рекомендуется использовать VPS со следующими характеристиками:
- **CPU:** 1 core
- **RAM:** 1 GB (рекомендуется 2 GB)
- **Disk:** 10 GB SSD
- **OS:** Linux (Ubuntu 22.04/24.04 рекомендуется)
- **Software:** Docker, Docker Compose
- **DNS:** Заранее направьте A-запись вашего домена на IP-адрес VPS.
- **Firewall:** Откройте порты 80 (HTTP) и 443 (HTTPS).

## 2. Безопасность (ВАЖНО)
- **Смена пароля:** После первой установки обязательно войдите под `admin` / `admin123` и смените пароль администратора.
- **Порты:** По умолчанию база данных работает только на `127.0.0.1` (недоступна из интернета).
- **Секреты:** Используйте уникальные значения для `AUTH_SECRET` и `POSTGRES_PASSWORD`.

## 3. Установка (Автоматическая)

### Linux (через скрипт)

```bash
# Клонируйте репозиторий
git clone https://github.com/tobolkind-coder/utm-link-builder3.git && cd utm-link-builder3

# Запустите скрипт установки
sudo bash install.sh
```

**Что спросит скрипт:**
1. **Domain:** Введите ваш домен (например, `go.company.ru`). Этот домен будет использоваться как для сайта, так и для формирования коротких ссылок.
2. **Email for SSL:** Введите ваш email для получения уведомлений от Let's Encrypt (опционально).

**Результат:**
После завершения скрипт выведет адрес страницы входа, логин и пароль. 
**Важно:** Корень домена (`https://<ваш-домен>`) намеренно отдаёт 404 в целях безопасности. Страница входа имеет уникальный случайный адрес (например, `https://<ваш-домен>/auth-1234567890abcdef`), который скрипт выведет в конце установки. Вы можете изменить этот путь в разделе "Admin > Settings".

### Windows (через Docker Desktop)
1. Установите [Docker Desktop](https://www.docker.com/products/docker-desktop/).
2. Запустите `install.bat`.

## 4. Обновление
Если вы используете git:
```bash
git pull
sudo bash install.sh
```

## 5. Решение проблем
- **Как попасть в админку после установки:**
  Если вы пропустили URL, выполните:
  ```bash
  docker compose logs web | grep "Login page"
  ```
- **Сайт недоступен:** Убедитесь, что DNS-запись домена настроена верно и порты 80/443 открыты на VPS.
- **SSL ошибки:** Если SSL не заработал, выполните принудительный перевыпуск:
  ```bash
  sudo bash scripts/init-ssl.sh <ваш-домен> <ваш-email>
  ```
- **Сайт недоступен сразу после установки (404/SSL ошибки):**
  Часто это вызвано попаданием невидимых управляющих символов терминала (escape-последовательностей) в переменную домена при вводе в скрипте.
  **Диагностика:** Выполните `cat -A .env | grep SHORT_DOMAIN`. Если видите странные символы в начале строки (например `^[[...`), переустановите сервис. В текущей версии скрипта (install.sh) добавлена автоматическая очистка и валидация домена.
- **Ошибка `failed to solve: Internal: rpc error...` при сборке:**
  Если при сборке возникает эта ошибка, попробуйте временно отключить BuildKit:
  ```bash
  export DOCKER_BUILDKIT=0
  docker compose build
  docker compose up -d
  ```
  Если ошибка повторяется, создайте issue в репозитории.
- **Логи:** `docker compose logs -f web`
