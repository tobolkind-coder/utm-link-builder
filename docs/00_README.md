# UTM Link Builder

## Описание

Внутренний корпоративный веб-сервис для генерации маркетинговых ссылок с UTM-метками и автоматическим созданием короткой ссылки на собственном домене.

Сервис предназначен для использования сотрудниками компании и не является публичным.

---

## Быстрая установка (для неопытных пользователей)

### Linux/Ubuntu

```bash
# Скачайте и запустите установщик
curl -sSL https://raw.githubusercontent.com/ваш-репозиторий/main/install.sh | sudo bash
```

Или скачайте проект и запустите:

```bash
cd utm-link-builder
sudo bash install.sh
```

### Windows

1. Установите [Docker Desktop](https://www.docker.com/products/docker-desktop/)
2. Запустите файл `install.bat`
3. Следуйте инструкциям

После установки откройте в браузере адрес, который покажет скрипт.

**Данные по умолчанию:**
- Логин: `admin`
- Пароль: `admin123`

---

## Основные возможности

- Авторизация пользователей
- Управление пользователями администратором
- Генерация UTM-ссылок
- Автоматическое удаление старых UTM-параметров
- Корректная обработка URL с существующими GET-параметрами
- Генерация коротких ссылок
- Автоматическое копирование короткой ссылки
- История последних ссылок пользователя
- Управление всеми справочниками UTM
- Настройка короткого домена
- Развертывание через Docker Compose
