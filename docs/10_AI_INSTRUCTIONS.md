# Backend

Вся бизнес-логика должна находиться на сервере.

React-компоненты не должны принимать бизнес-решения.

Все проверки доступа должны выполняться только на сервере.

---

# Frontend

Frontend отвечает только за:

- отображение данных;
- взаимодействие с пользователем;
- отправку запросов;
- отображение ошибок;
- отображение результатов.

---

# Работа с базой данных

Использовать только Prisma ORM.

Не использовать Raw SQL без объективной необходимости.

Все миграции должны выполняться через Prisma.

# Безопасность

Не доверять данным клиента.

Все входящие данные проверять на сервере.

Не логировать:

- cookie;
- токены;
- секретные ключи;
- содержимое переменных окружения.
